Here's a concise LaTeX summary of the key classification metrics:

```latex
\begin{itemize}
    \item \textbf{Accuracy}: Measures overall prediction correctness:
    \[
    \text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}
    \]
    where $TP$, $TN$, $FP$, and $FN$ denote true positives, true negatives, false positives, and false negatives respectively.

    \item \textbf{F1-score}: Harmonic mean of precision and recall:
    \[
    \text{F1} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}
    \]
    Balances false positives and false negatives, ideal for imbalanced datasets.

    \item \textbf{AUC-ROC}: Area Under the Receiver Operating Characteristic curve:
    \[
    \text{AUC} = \int_0^1 TPR(FPR) \, dFPR
    \]
    Measures model's ability to distinguish classes across all thresholds (1 = perfect, 0.5 = random).
\end{itemize}
```

### could acronym latex package be set to define the complete acronym the first time in a new section?

The `acronym` LaTeX package does **not** automatically reset acronyms at the beginning of new sections by default. Once an acronym is defined with `\ac{XYZ}` or `\acf{XYZ}`, it will use the short form (`XYZ`) for the rest of the document unless you manually reset it.

---

### How to Reset Acronyms per Section/Chapter

To make acronyms reset at each new section (or chapter), you can **redefine the sectioning command** to reset the acronyms. Here’s how:

#### Step 1: Include the `acronym` package
```latex
\usepackage[printonlyused]{acronym} % or just \usepackage{acronym}
```

#### Step 2: Add this code to your preamble (before `\begin{document}`)
```latex
\usepackage{etoolbox} % Required for patching commands

% Reset acronyms at every section
\pretocmd{\section}{\global\expandafter\let\csname ac@XYZ\endcsname\relax}{}{}
% Replace 'XYZ' with each of your acronyms

% To reset all acronyms automatically for every section:
\newcommand{\resetacronyms}{%
  \forcsvlist{\resetac}{LIST-OF-ALL-YOUR-ACRONYMS}%
}
\pretocmd{\section}{\resetacronyms}{}{}
```

> ⚠️ However, manually listing all acronyms is tedious. A better way is:

#### Step 3 (Better): Use `\acresetall` at each section
If you want to reset **all** acronyms at the beginning of every section, use:

```latex
\usepackage{acronym}
\pretocmd{\section}{\acresetall}{}{}
```

Or if you want to reset only specific ones, use:
```latex
\pretocmd{\section}{\acused{XYZ}}{}{} % Reset specific acronym
```
