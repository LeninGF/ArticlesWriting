Yes, you can make figures take up less space in the Springer LaTeX format by:

1. **Reducing the width of the figure:**  
   Use a width smaller than `\linewidth` (e.g., `0.6\linewidth`).

2. **Using the `figure*` or `[h]` placement specifier wisely:**  
   Use `[h]` or `[htb]` to encourage LaTeX to place the figure closer to where it appears in the text.

3. **Wrapping text around the figure:**  
   Use the `wrapfig` package to make the text flow next to your figure.

**Example using `wrapfig`:**

```latex
\usepackage{wrapfig}

\begin{wrapfigure}{r}{0.5\textwidth} % 'r' for right, width of the figure
  \centering
  \begin{subfigure}[b]{0.95\linewidth}
    \includegraphics[width=\linewidth]{./images/histogramOriginalDataset.png}
    \caption{Original Dataset Histogram}
  \end{subfigure}
  \vspace{0.2cm}

    \caption{Box plot}
  \end{subfigure}
  \caption{Distribution of word counts in collected data.}
  \label{fig:dataset-visualizations}
\end{wrapfigure}
```

**Usage tips:**
- Adjust `{r}` to `{l}` to place the figure on the left.
- Tune the `{0.5\textwidth}` value as needed.
- Place the `wrapfigure` in your text where you want wrapping to start.  
- Make sure to add sufficient text after the figure to avoid formatting issues.

This method saves space and allows the text to flow beside your figure for more efficient page usage.

### use python to read both images and then make them of the same size and save them

Here's a Python script to read both images, resize them to the same dimensions, and save them:

```python
from PIL import Image
import os

def resize_images_to_same_size(image1_path, image2_path, output_dir=None, target_size=None):
    """
    Resize two images to the same dimensions
    
    Args:
        image1_path: Path to first image
        image2_path: Path to second image  
        output_dir: Directory to save resized images (optional)
        target_size: Target size as (width, height) or None for auto
    """
    
    # Read images
    img1 = Image.open(image1_path)
    img2 = Image.open(image2_path)
    
    print(f"Original sizes:")
    print(f"Image 1: {img1.size}")
    print(f"Image 2: {img2.size}")
    
    # Determine target size
    if target_size is None:
        # Use the larger dimensions from both images
        max_width = max(img1.size[0], img2.size[0])
        max_height = max(img1.size[1], img2.size[1])
        target_size = (max_width, max_height)
    
    print(f"Target size: {target_size}")
    
    # Resize images (using LANCZOS for high quality)
    img1_resized = img1.resize(target_size, Image.Resampling.LANCZOS)
    img2_resized = img2.resize(target_size, Image.Resampling.LANCZOS)
    
    # Determine output paths
    if output_dir is None:
        output_dir = os.path.dirname(image1_path)
    
    # Create output filenames
    base1, ext1 = os.path.splitext(os.path.basename(image1_path))
    base2, ext2 = os.path.splitext(os.path.basename(image2_path))
    
    output1 = os.path.join(output_dir, f"{base1}_resized{ext1}")
    output2 = os.path.join(output_dir, f"{base2}_resized{ext2}")
    
    # Save resized images
    img1_resized.save(output1)
    img2_resized.save(output2)
    
    print(f"Resized images saved to:")
    print(f"  {output1}")
    print(f"  {output2}")
    
    return output1, output2
```

```python
def resize_with_padding(image1_path, image2_path, output_dir=None, target_size=None):

    """
    img1 = Image.open(image1_path)

        max_width = max(img1.size[0], img2.size[0])

    img1_padded.save(output1)
    img2_padded.save(output2)
```
